# Продсервис

B2B-сайт поставщика продуктов для HoReCa: каталог, личный кабинет с персональными ценами, админка и обмен с 1С:Комплексная автоматизация.

Стек: Next.js 16 · Payload CMS 3 (админка и API) · PostgreSQL 16 · TypeScript.

## Цены

Цена клиента считается в `src/lib/pricing/resolvePrice.ts`, первое совпадение выигрывает:

1. Индивидуальная цена клиента на товар на период (из 1С).
2. Цена торгов для сети клиента на период (из 1С).
3. Прайс клиента (Прайс 2, 3, 4…).
4. Гостевой прайс (настраивается в «Настройки сайта»).

Цены всех прайсов закрыты от публичного API: покупатель получает только свою итоговую цену.

## Локальный запуск

```bash
cp .env.example .env        # заполнить DATABASE_URL и PAYLOAD_SECRET
pnpm install
pnpm dev                    # http://localhost:3000, админка — /admin
pnpm seed:demo              # демо-прайсы, товары, сеть, клиент, торги
pnpm test:int               # тесты
```

Демо-доступы (только для локальной базы): `admin@prodservis.local / admin12345`, клиент `client@prodservis.local / client12345`.

## Структура

- `src/collections` — товары, категории, подборки, прайсы, торги и инд. цены, клиенты, сети, заказы, страницы, медиа, сотрудники
- `src/globals/SiteSettings.ts` — контакты, условия заказа, гостевой прайс, баннеры
- `src/access` — роли: администратор, менеджер по продажам, контент-менеджер
- `src/lib/pricing` — расчёт цены клиента
